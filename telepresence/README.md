# Furhat Telepresence Demo

A telepresence interface for Furhat, where you can:

* See the camera feed, and click on people to let Furhat attend to them
* Listen in to the robot's microphone
* Transfer your head movements and facial expressions to the robot
* Transfer your voice through the robot's speakers with automatic lipsync added

Start the server with:

```
python -m http.server
```

Then open a webbrowser on http://127.0.0.1:8000/
